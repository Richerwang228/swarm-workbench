# Support

This is a community-maintained portfolio project, not a hosted service.

- Reproducible bug: open a GitHub issue with environment and logs.
- Feature proposal: start a discussion in an issue before implementation.
- Security problem: follow [SECURITY.md](SECURITY.md), never a public issue.
- Provider billing, quota, or model behavior: contact that provider.

Please remove secrets and personal data from all logs before posting them.
